# Rock Paper Scissors

An early JavaScript project I built independently while learning front-end development.

The project was created to practise turning basic JavaScript concepts into an interactive browser game, including DOM manipulation, event handling, game logic and updating the interface from user actions.

I used videos and other learning resources to understand individual techniques while building it, but this implementation and presentation were put together as my own project rather than as a follow-along tutorial.

## Built With

- HTML
- CSS
- JavaScript

## Context

This repository is kept as part of my development history and reflects an earlier stage of my JavaScript learning.
